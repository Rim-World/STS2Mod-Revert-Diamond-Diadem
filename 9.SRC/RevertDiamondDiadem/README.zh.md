# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ① 效果

将先古遗物“钻石头冠”的效果由 111 版本的“战斗开始时获得 20 点格挡，且格挡在第 2 回合开始前不会被移除”回调为 109 版本之前的效果：玩家回合结束时结算，若本回合打出的牌少于等于 2 张，则在敌方回合内受到敌人的攻击伤害减半。

本 mod 直接在“钻石头冠”原遗物上进行修改，并非生成新遗物 + 禁用旧遗物。

## ② 影响（基于本人游戏理解）

新旧钻石头冠各有优劣：109版本后的新版钻石头冠在道中具有更强的止损能力，109版本前的旧版则面对三层boss有更强大的发挥。

但整体来讲，我认为旧版的钻石头冠更有设计感和博弈乐趣，且整体强度略高于新版头冠。

本 mod 影响存档：在 mod 开启时，历史记录中的“钻石头冠”遗物描述按回调后的文案显示；关闭 mod 后会恢复原状。

## ③ 环境与版本

本 mod 需要先安装基础库 STS2-RitsuLib 。

本 mod 支持 0.109.0 及以上版本，适用目前的public beta 111 版本；default 0.107.x 及更早版本不会加载本 mod，但未来版本更新后自动适配。

在钻石头冠仍为旧效果的版本上自动停用：该版本的钻石头冠本就是目标效果，无须修改。

游戏启动时 mod 检测游戏包体中钻石头冠的实现形态（是否为开局触发逻辑、原专属减伤 buff 是否缺失），仅在新效果版本上生效；遗物被移除或形态改变时，本 mod 自动禁用，不会报错或崩溃。

理论上只要没有大的 api 更新或遗物修改，本 mod 无须修改即可自动适配新版本。

## ④ 语言支持

本 mod 的遗物与 buff 文本共提供 16 种语言——deu / eng / esp / fra / ind / ita / jpn / kor / pol / ptb / rus / spa / tha / tur / zhs / zht。

其中 13 种语言与 v0.107.1 官方文本完全一致；

zht（繁体中文）因 107 版本官方未提供，由 zhs 简体文案转写；

tha（泰语）的一个词因 107 官方泰语未翻译而采用 eng 文本（此为游戏在文案缺失时的自动回落行为），描述文案为 107 官方泰语；

ind（印尼语）为 107 版本未提供的语言，采用 eng 文本兜底。

## ⑤ 实现方式与兼容性

本 mod 基于 STS2-RitsuLib 框架写成，修改遗物行为的核心为外置补丁写死：出牌计数、回合末判定、减伤 buff 的施加与移除、计数器 UI、遗物描述文本均固定为 107 版本的效果；

减伤 buff 为 mod 自建类（官方在 111 版本删除了原 buff 类），其名称、图标与文本均指向 107 官方原资源（这些资源未被删除）。

本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
