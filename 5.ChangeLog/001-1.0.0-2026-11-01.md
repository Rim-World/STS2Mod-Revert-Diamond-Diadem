# 001 — 1.0.0

| 字段 | 内容 |
|---|---|
| 版本号 | `1.0.0`（manifest `version` 字段；2026-08-28 由 `0.1.0` 定为正式发布号） |
| 时间戳 | 源码末次提交 2026-08-30；本版本发布日 2026-11-01 |
| 开发人员反馈 | 三轮游戏内验收的反馈已全部处置：计数跨回合不归零、buff 永久常驻、buff 图标显示为占位图。图标方案经历「自带 png → 依赖官方 slug 路径 → 补丁指回官方原类资源路径」三次迭代后定稿。 |
| 实装更改概括 | 首个正式版本。在钻石头冠为 beta 111 式新效果的宿主上，将该遗物回调为 default 107 行为：回合结束统计本回合出牌数，≤2 张时施加「受普通攻击伤害减半」buff，持续到该次敌方回合结束；恢复遗物出牌计数器与 Active 高亮；遗物描述改用 107 文案。在旧效果宿主上整个 mod 不产生任何补丁。 |
| 简略技术细节 | 基于 STS2-RitsuLib ≥ 0.5.15 的 `IPatchMethod` 补丁框架，共 10 个补丁类挂在 patcher `revert_main` 下；`HostShapeGate` 用「`DiamondDiadem` 是否自有 `AfterSideTurnStart` override」+「官方 `DiamondDiademPower` 类型是否缺失」两个反射判据决定启用；计数存于 `ConditionalWeakTable`，阈值硬编码 2；`ModifyDamageMultiplicative` 按 107 五参与 111 六参双签名 Optional 目标挂载 postfix 实现减半；自建 `RevertDiamondDiademPower` 并在 `AfterSideTurnEnd(side==Enemy)` 移除；文本用独立键 `RE_DIAMOND_DIADEM.description` 与 `REVERT_DIAMOND_DIADEM_POWER.*`，16 语言；图标指回官方原类资源路径，mod 不自带图片。manifest `min_game_version` = `0.109.0`。 |
| 失败经验或实验教训 | ① 计数清零后必须调用 `InvokeDisplayAmountChanged`，否则 UI 停在旧值；② 复刻官方 buff 时漏掉 `AfterSideTurnEnd` 的移除会导致永久常驻；③ mod pck 内的原始 png 没有 `.import` remap，运行时无法加载，自带图片方案不可行；④ 官方按类名 slug 推图标路径，类名带 `Revert` 前缀必然落到占位图，正确解法是补丁改写 getter 指向官方原类资源；⑤ 官方删除内容型代码时通常不清理美术资源，可直接依赖残留资源路径。 |
